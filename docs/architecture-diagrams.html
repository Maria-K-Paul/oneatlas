OneAtlas Architecture

One Next.js 16 app on Vercel serves both the website and the public REST API, reading from Neon Postgres through Prisma. Only the ingestion pipeline writes to the database.

Database schema

7 tables. A lab creates models; providers serve them, and the price lives on the pair.

erDiagram
  Lab ||--o{ Model : creates
  Lab |o--o{ Provider : "runs own API"
  Model ||--o{ ModelOffering : "offered as"
  Provider ||--o{ ModelOffering : serves
  Model ||--o{ BenchmarkScore : "scored on"
  Benchmark ||--o{ BenchmarkScore : records

  Lab {
    string id PK
    string slug UK
    string name
    enum kind
    string headquarters
    int foundedYear
  }
  Provider {
    string id PK
    string slug UK
    string name
    enum kind
    string labId FK "nullable"
  }
  Model {
    string id PK
    string labId FK
    string slug "unique per lab"
    string name
    enum type
    enum status
    date releaseDate
    int contextWindow
    int maxOutputTokens
    enum_list inputModalities
    enum_list capabilities
    bool openWeights
    decimal minInputPrice "derived"
    decimal blendedPrice "derived"
    int providerCount "derived"
  }
  ModelOffering {
    string id PK
    string modelId FK
    string providerId FK
    string providerModelId
    enum pricingUnit
    decimal inputPrice
    decimal outputPrice
    decimal cachedInputPrice
    int contextWindow "override"
  }
  Benchmark {
    string id PK
    string slug UK
    string name
    enum category
    enum unit
    bool higherIsBetter
  }
  BenchmarkScore {
    string id PK
    string modelId FK
    string benchmarkId FK
    float score
  }
  IngestionRun {
    string id PK
    string source
    enum status
    datetime finishedAt
    json stats
  }
PK primary key UK unique FK foreign key derived recomputed by ingestion from offerings Prices: DECIMAL(10,4) USD per unit, never floats
Lab ≠ ProviderMeta makes Llama; Groq, Together and Bedrock serve it. ModelOffering holds each provider's price.
Public ids are slugsanthropic/claude-opus-4-5, unique per lab, like Hugging Face and OpenRouter.
Indexed for every filterGIN on capability and modality arrays, trigram on names, B-tree on price, context and release date.
Checked twiceZod rejects bad data at ingestion; Postgres CHECK constraints block negative prices and malformed slugs anyway.
